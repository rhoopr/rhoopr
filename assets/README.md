# Artwork and font provenance

`stone-face.webp`, `synctoken-print.webp`, and `github-print.webp` are artwork-only crops of the AI-generated visual approved by Rob Hooper for this redesign (ChatGPT Library file `libfile_88bf46b39f388191bd97a8ec13332e72`, original PNG `exec-9b6282c1-edd2-4219-bcc1-649ce254d74b.png`). No third-party photograph is used, and all site text is HTML.

`print-grain.svg` and `worn-edge.svg` are procedural SVG textures created for this site.
